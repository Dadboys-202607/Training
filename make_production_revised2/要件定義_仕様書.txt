[要件定義]

目的：月ごとのシートの生産量と在庫量をPythonで計算し、「_出力」シートに書き込む。


入力

「処理対象」シートのA1に年、A2に月を入れる。指定した「YYYY.M」シートを処理する。
（月は前に0を付けない。例：2026.9、2026.10）
使うデータ：消費量（4〜6行目）、前月末在庫（B12〜B14）、閾値と発注量（B17:C19）
日付は2行目にあり、列の数は月によって変わる。
消費量は全日入力必須とする。（土日は0）
「YYYY.M」シートは自動では作成せず、最初から存在しているものとする。

計算ルール

前日の在庫が閾値以下（<=）で、平日なら、その日に発注量だけ生産する。
1日1回まで。土日は発注しない。
在庫 = 前日在庫 − 消費量 + 生産量
1日目の前日在庫は前月末在庫とする。
※本プログラムにおいては月～金の祝日は平日扱いとする。

前月末在庫

前月は、1月の場合は前年の12月とする（例：2027.1 の前月は 2026.12）。
前月の入力シートがない場合は、最初の月とみなし、B12〜B14の手入力値を使う。
前月の入力シートと「_出力」シートがある場合は、その「_出力」シートの最終日の在庫を使う。
前月の入力シートはあるのに「_出力」シートがない場合は、エラーで止める。

出力

入力シートをコピーして「YYYY.M_出力」を作り、入力シートのすぐ後ろに置く。同じ名前のシートがあれば作り直す。
生産量（発注しない日は0を入力する）、在庫量（数値）、前月末在庫を書き込む。
元のファイルに上書き保存する。入力シートには書き込まない。

運用上の注意

前月を再実行した場合は、それ以降の月も順に再実行すること。




[外部仕様書]

外部仕様書：生産量自動入力プログラム

1. 実行方法
  python make_production.py 生産計画自動計算.xlsx
  ・引数には対象のExcelファイル（.xlsx）のパスを1つ渡す。
  ・実行前に、Excelでそのファイルを閉じておくこと。

2. 事前準備（利用者が行う作業）
  ・「処理対象」シートのA1に年（例：2026）、A2に月（例：9）を入れる。
    月が一桁の場合は前に0を付けない。
  ・処理対象の「YYYY.M」シートに、消費量を全日入力する（土日は0）。
  ・最初の月（前月のシートがない月）だけ、B12〜B14に前月末在庫を入力する。

3. 処理結果
  ・「YYYY.M_出力」シートを、入力シートのすぐ後ろに作る。
    同じ名前のシートがあれば置き換える。
  ・出力シートの内容
    生産量（8〜10行目）
      発注した日は発注量、発注しない日は0（数値）を入力。
    在庫量（12〜14行目）
      計算した在庫の数値（数式ではない）。
    前月末在庫（B12〜B14）
      前月の「_出力」シートの最終日の在庫。
      最初の月は手入力の値のまま。
    その他のセル
      入力シートと同じ。
  ・入力シートと前月の「_出力」シートは書き換えない。
  ・前月を再実行した場合は、それ以降の月も順に再実行すること。

4. 発注ルール
  ・前日の在庫が閾値以下（=を含む）になっていたら、その日に発注量だけ生産する。
  ・1日目の前日の在庫は前月末在庫とする。
  ・1日1回まで。土日は発注しない。
  ・本プログラムにおいては月～金の祝日は平日扱いとする。

5. 画面に出るメッセージ
  5.1 正常に終了した場合
    2026.10_出力 を作成しました。
      部品A：発注 3回
      部品B：発注 2回
      部品C：発注 2回
    ※発注回数は、生産量が0でない日の数。

  5.2 エラーの場合（ファイルは保存しない）
    ・引数がない、または2つ以上ある
        Excelファイルを1つ指定してください
    ・ファイルが見つからない
        ファイルが見つかりません：<パス>
    ・「処理対象」シートがない
        「処理対象」シートがありません
    ・A1かA2が空欄、または正しくない（年は4桁の整数、月は1〜12の整数）
        処理対象の年月が正しくありません
    ・指定した月の入力シートがない
        シート「2026.10」がありません
    ・前月の入力シートはあるが、前月の「_出力」シートがない
        シート「2026.9_出力」がありません。前月を先に実行してください
    ・最初の月の前月末在庫が空欄
        前月末在庫（B12〜B14）を入力してください
    ・消費量に空欄または数値ではない値が入っている
        消費量の値が異常です：<シート名>!<セル>
    ・前月末在庫（B12〜B14、または前月「_出力」の最終日の在庫）、
      閾値・発注量（B17:C19）に空欄または数値ではない値が入っている
        数値でない値があります：<シート名>!<セル>
    ・保存に失敗した
        保存できません。Excelでファイルを閉じてから実行してください




[内部仕様書]

使用ライブラリ：openpyxl
※ load_workbook は data_only=True を使わない（保存時に入力シートの数式が値に置き換わるため）。
※ エラー時は外部仕様書5.2のメッセージを表示し、保存せずに終了コード1で終了する。

1. 引数とファイルのチェック
   1-1. sys.argv の引数が1つでなければ「Excelファイルを1つ指定してください」。
   1-2. path = 引数。path のファイルが存在しなければ「ファイルが見つかりません：<path>」。

2. ブックを開く
   wb = load_workbook(path)

3. 処理対象の年月を読む
   3-1. 「処理対象」シートが wb になければエラー。
   3-2. y = A1、m = A2 を読む。
        どちらかが空欄、整数でない、y が4桁でない、m が1〜12でない場合はエラー。
        （Excelで数値が 10.0 のように小数で読まれた場合は、整数値なら int に変換してよい）
   3-3. name = f"{y}.{m}"     例：2026.9（0は付けない）
        out_name = name + "_出力"
   3-4. name のシートがなければ「シート「<name>」がありません」。
        ws_in = wb[name]
   3-5. 前月を求める。
        m == 1 なら prev_y = y - 1、prev_m = 12
        それ以外なら prev_y = y、prev_m = m - 1
        prev_name = f"{prev_y}.{prev_m}"
        prev_out_name = prev_name + "_出力"

4. 日付の列を求める
   C列（3列目）から右へ、2行目の値が日付（datetime）である間の列を cols とする。
   ※ max_column は書式だけのセルも数えるため使わない。

5. 前月末在庫 pre_stock[3] を決める（部品A,B,C の順）
   5-1. prev_name のシートが ない 場合（最初の月）：
        pre_stock = ws_in の B12, B13, B14
        いずれかが空欄なら「前月末在庫（B12〜B14）を入力してください」。
        数値でなければ「数値でない値があります：<name>!<セル>」。
        from_prev = False
   5-2. prev_name のシートが ある 場合：
        prev_out_name のシートがなければ
          「シート「<prev_out_name>」がありません。前月を先に実行してください」。
        ws_prev = wb[prev_out_name]
        ws_prev の2行目で日付が入っている最後の列を last_col とする（4. と同じ方法）。
        pre_stock = ws_prev の (12, last_col), (13, last_col), (14, last_col)
        空欄または数値でなければ「数値でない値があります：<prev_out_name>!<セル>」。
        from_prev = True

6. 閾値・発注量を読む（当月の入力シート ws_in から）
   threshold[i] = B17, B18, B19
   order_qty[i] = C17, C18, C19
   空欄または数値でなければ「数値でない値があります：<name>!<セル>」。

7. 計算（入力シートには書き込まず、結果はリストに保持する）
   部品 i = 0,1,2（消費量の行 = 4+i、生産量の行 = 8+i、在庫の行 = 12+i）について：
     prev = pre_stock[i]
     count[i] = 0
     cols の各列 c について、次の順で処理する：
       (1) cons = 消費量セル(4+i, c)
           空欄または数値でなければ「消費量の値が異常です：<name>!<セル>」。
       (2) 生産量を決める（当日の在庫を計算する前に、前日の在庫で判定する）
           当日の日付 d = (2, c) の値
           d.weekday() < 5（月〜金。祝日も平日扱い）かつ prev <= threshold[i] なら
             prod = order_qty[i]、count[i] += 1
           それ以外は prod = 0
       (3) stock = prev - cons + prod
       (4) prod_list[i][c] = prod、stock_list[i][c] = stock
       (5) prev = stock
   ※ 3行目の曜日の文字は判定に使わない。
   ※ 入力シートの8〜10行目（生産量）は読まない。

8. 出力シートを作る
   8-1. out_name のシートがすでにあれば wb.remove() で削除する。
   8-2. ws_out = wb.copy_worksheet(ws_in)、ws_out.title = out_name
   8-3. ws_out はブックの末尾に作られるので、ws_in のすぐ後ろへ移動する。
        wb.move_sheet(ws_out, offset = (ws_in の位置 + 1) - (ws_out の位置))


9. 出力シートに書き込む
   部品 i、列 c ごとに：
     ws_out.cell(8+i, c)  = prod_list[i][c]    （0 または発注量）
     ws_out.cell(12+i, c) = stock_list[i][c]   （数値。数式を上書きする）
   from_prev が True なら：
     ws_out の B12, B13, B14 = pre_stock[0], pre_stock[1], pre_stock[2]

10. 保存
   wb.save(path)
   PermissionError が出たら「保存できません。Excelでファイルを閉じてから実行してください」。

11. メッセージを表示する
   「<out_name> を作成しました。」
   「  部品A：発注 <count[0]>回」
   「  部品B：発注 <count[1]>回」
   「  部品C：発注 <count[2]>回」
